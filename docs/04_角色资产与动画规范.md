# 04｜Q版角色资产与动画包规范（第 34 轮）

## 1. 美术定位与界限

正式默认角色：原创 Q 版 2D「银白科技研究员」，女孩子气质，银白短发、轻盈刘海、冰蓝眼睛、白蓝科技制服、银白/冰蓝及少量金色点缀，约 2.5 头身。**正式角色名待定。**

本包 `assets/prototype_chibi/` 是**程序化绘制的简化几何占位角色**，用于 V0.0 原型比较，绝非已完成正式角色立绘、也不能拿来作为最终 30+ 动作验收素材。

## 2. 资源包约定（V0.0，非最终稳定 API）

```text
assets/prototype_chibi/
├── manifest.json
├── LICENSE.txt
├── atlas.png
└── animations/
    ├── idle/000.png ...
    ├── walk/000.png ...
    ├── jump/000.png ...
    └── drag/000.png ...
```

`manifest.json` 必须包含：角色 ID、画布尺寸、frame rate、四类 action 配置、单帧文件列表、anchor/碰撞盒、可循环性、spritesheet 列/行数及素材标记。

示例资源的每张序列帧：256x256 RGBA PNG；统一角色基准落点为 `anchor_normalized=[0.5,0.9]`，动作可由图片中的高度差表现，实际触地/跳跃由引擎的物理坐标驱动。原型将同一份资源传给不同候选方案，不准一方使用轻量图、另一方使用大贴图却直接比性能。

## 3. 动作可验收定义

| 动作 | 触发 | 必要效果 |
|---|---|---|
| idle | 空闲 | 连续多帧、循环 |
| walk | 水平移动 | 交替步伐，多帧循环 |
| jump | 跳跃 | 离地到落地，表现运动轨迹（角色物理位移独立） |
| drag | 指针按住实体拖动 | 角色改变姿势，释放回正常状态 |

每个动作在同一真实程序中演示，至少包含 4 张**有可观察差异**的帧；不以单图缩放、单图旋转冒充多帧动画。用户第24题最终要求 30+ 类动作，在 V2.0 才要求满足。

## 4. 角色与皮肤的身份关系

- `character_id` 永久身份，挂载人格、记忆、成长、社交关系。
- `appearance_id` 是皮肤/换装标识，切换不得修改 character_id 和记忆。
- `action_id` 与角色外观解耦，同名动作可以适配不同人物的独立素材。
- `voice_id` 及 `provider_id` 是独立的 TTS 配置，不能绑死在动画文件。

## 5. 未来导入验收（V1.5）

对 manifest 版本、文件格式、RGBA/分辨率、动作帧列表、循环 FPS、名称冲突、文件数量和解压大小做限制。拒绝 `../`、绝对路径、符号链接越界、可执行脚本、远程 URL 自动拉取。外部导入默认只允许数据素材，不执行内嵌程序。

## 6. 素材生产与版权

技术试验素材均由本工具本地程序生成（无第三方素材）。未来 AI/手绘/PS/已获许可资产可混合制作，必须按角色包记录素材来源、使用权范围、作者/创作方式和导入日期。不得将未经许可的现成角色形象宣称原创。
