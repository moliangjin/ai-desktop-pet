# 05｜架构边界与技术选型决策记录模板

版本：1.0。**本文件不是技术栈决定书。**

## 1. 目标边界（不预设语言/框架）

- `DesktopHost`: 窗口、鼠标命中与透明区事件策略、多屏/Spaces、层级、隐藏、焦点管理。
- `AnimationRuntime`: 角色 Sprite 资源加载、动画帧调度、动作状态机、位移/碰撞、资源回收。
- `CharacterDomain`: 角色 ID、外观 ID、动作名、配置，不依赖具体窗口框架。
- `AIProvider`: 后续 V0.5 的文本请求统一接口，可替换 Provider，不在 V0.0 实现联网聊天。
- `TTSProvider`: 后续 V0.5 的独立语音回复接口，不在 V0.0 发语音 API。
- `MemoryStore`: 后续 V0.5 的数据存储接口，持久化与备份/安全规划先写接口，不在 V0.0 实现真正个人数据存储。
- `SettingsAndPrivacy`: 后续扩展的设置、权限、备份、日志模块。

优先保证少而清晰的隔离，不要为了形式主义建设过多空包/伪服务。

## 2. 最低限度可移植数据契约

- 角色配置：JSON + 版本号，资源引用相对路径。
- 动画配置：action ID、frames、FPS、loop、anchor、hitbox。
- 记忆和事件：后续定义独立模型，不绑定特定操作系统数据库位置。
- AI/TTS 设置：引用安全密钥标识符，不在 JSON 中放真正 Key。
- 所有外部素材路径做安全归一化；禁止从未受信任角色包加载脚本。

## 3. 候选可行性验证要点

- **Swift/AppKit/SpriteKit**：原生鼠标命中与 NSWindow ignoresMouseEvents 的切换可行性，视图组合/性能、纯 Mac 路线 Windows 移植成本。
- **Electron/PixiJS**：透明窗口、setIgnoreMouseEvents 与命中区域的配合，打包大小/Chromium 常驻成本。
- **Tauri 2/WebGL**：透明 WebView 在 macOS 上的配置/私有 API/分发限制，窗口命中精度，Rust/JS 构建可维护性。
- **原生 + 可移植核心**：若确有收益，再比较 IPC、复杂度、调试和回归成本，不把“跨平台”宣传当作实测成绩。

参考官网：
- https://developer.apple.com/documentation/appkit/nswindow/ignoresmouseevents
- https://www.electronjs.org/docs/latest/api/browser-window
- https://v2.tauri.app/reference/javascript/api/namespacewebview/

官方 API 的存在仅表明相应窗口级能力可调用，不保证“透明像素准确识别后又能点击实体区域”自然成立；必须交由 V0.0 真实验证。
