## 一、GATE 3 三个验证动作（R122 §六 指定）

R122 §六 要求为未来 GATE 3 定义三个验证动作：

1. **idle**：待机呼吸、眨眼
2. **walk**：角色自然左右行走
3. **sleep**：坐下或躺下、入睡、睡醒

> 「这三个动作目前仅作为后续 GATE 3 的制作规格。」

---

## 二、idle — 待机呼吸 + 眨眼

### 2.1 呼吸循环

| 项 | 值 |
|---|---|
| 动作 ID | `idle_breath` |
| 帧数 | 6 帧 |
| 帧率 | 6 fps |
| 循环 | ✅ 是（loop） |
| 单次时长 | 6 / 6 = **1.0 秒** |
| 画布 | 512 × 512 |
| 锚点 | (0.5, **0.90**) — 脚底贴地 |
| 素材格式 | PNG 序列帧 |
| 文件名 | `scientist_idle_breath_front_{00..05}.png` |

**动作描述**：
- 胸腔轻微起伏（±1.5 px @512）
- 头部随呼吸微升微降（±1 px）
- 手臂自然垂放，无明显位移
- 脚底**完全不动**（锚点稳定性检查点）

### 2.2 眨眼（分层切换，非重绘）

| 项 | 值 |
|---|---|
| 动作 ID | `blink` |
| 帧数 | 3 帧（睁眼 → 半闭 → 闭眼） |
| 帧率 | 12 fps |
| 循环 | ❌ 否（一次性） |
| 单次时长 | 3 / 12 = **0.25 秒** |
| 实现方式 | **仅替换眼部图层**，身体层保持 idle_breath 帧 |
| 素材 | `scientist_eye_open.png` / `scientist_eye_half.png` / `scientist_eye_closed.png` |

**触发逻辑（运行时，非本轮实现）**：
- 随机间隔 3–8 秒触发
- 与 `idle_breath` 并行，不打断呼吸

### 2.3 idle 组一致性检查点

| 检查项 | 通过标准 |
|---|---|
| 呼吸帧间脚底 y 坐标 | 6 帧全部一致（±0 px） |
| 呼吸帧间左右边缘 x | 6 帧全部一致（±0 px） |
| 角色头部轮廓 | 6 帧形状一致，仅整体微位移 |
| 眨眼期间身体层 | 与 idle_breath 当前帧完全一致（不重绘） |

## 三、walk — 左右行走

### 3.1 行走循环

| 项 | 值 |
|---|---|
| 动作 ID | `walk_left` |
| 帧数 | 8 帧 |
| 帧率 | 10 fps |
| 循环 | ✅ 是（loop） |
| 单次时长 | 8 / 10 = **0.8 秒** |
| 画布 | 512 × 512 |
| 锚点 | (0.5, **0.90**) |
| 文件名 | `scientist_walk_left_front_{00..07}.png` |
| 右向版本 | `scientist_walk_right_front_{00..07}.png`（**由 left 镜像导出**） |

**动作描述**：
- 双腿交替迈步（Q 版幅度：前后摆动 ±14 px @512）
- 手臂与腿反向摆动
- 身体轻微上下起伏（±2 px，步频 2×）
- 支撑脚底始终落在锚点线上

### 3.2 右向素材生成规则（关键）

> R122 §五 4 / R119 §六 3：**禁止运行时使用 `scale.x = -1` 翻转。**

| 步骤 | 操作 |
|---|---|
| 1 | 美术只绘制 `walk_left` 8 帧 |
| 2 | 在**导出阶段**用图像工具做水平镜像，生成 `walk_right` 8 帧 |
| 3 | 运行时根据移动方向切换纹理，**不做运行时翻转** |
| 4 | 光影方向：镜像后需**人工修正**高光/阴影侧向（若原图光源偏左） |

**光源说明**：本角色规范光源为 45° 左上 → 右下，且**不随朝向改变**。因此镜像后需检查高光是否仍在左上。若美术绘制时已按「左上光」绘制，镜像后高光会跑到右上，**必须逐帧修正**。

### 3.3 walk 组一致性检查点

| 检查项 | 通过标准 |
|---|---|
| 8 帧循环接缝 | 第 7 帧 → 第 0 帧无跳变（腿部位置连续） |
| 支撑脚底 y | 所有帧一致（±0 px） |
| 角色整体 x 中心 | 所有帧居中（±2 px @512） |
| 右向 vs 左向 | 除水平镜像外，垂直结构完全一致 |
| 光源方向 | 左向/右向均为左上光（若不一致，判定 FAIL） |

## 四、sleep — 坐下/躺下、入睡、睡醒

这是 GATE 3 中最复杂的一组，包含**多个子动作 + 姿态转换 + 锚点切换**。

### 4.1 子动作拆解

| 子动作 ID | 描述 | 帧数 | 帧率 | 循环 | 锚点 y | 时长 |
|---|---|---|---|---|---|---|
| `sit_down` | 站姿 → 坐姿 | 6 | 10 | ❌ | 0.90→0.86（过渡） | 0.6 s |
| `sit_rest` | 坐姿静止 | 4 | 4 | ✅ | **0.86** | 1.0 s |
| `lie_down` | 坐姿 → 躺姿 | 6 | 8 | ❌ | 0.86→0.78（过渡） | 0.75 s |
| `sleep_idle` | 躺姿睡眠呼吸 | 4 | 3 | ✅ | **0.78** | 1.33 s |
| `wake_up` | 躺姿 → 坐姿 → 站姿 | 8 | 10 | ❌ | 0.78→0.90（过渡） | 0.8 s |

### 4.2 完整 sleep 状态机

```
[站姿 idle_breath]
      │ 触发 sleep 行为
      ▼
  sit_down (0.6s, 锚点 0.90→0.86)
      ▼
  sit_rest (循环 1.0s, 锚点 0.86)  ← 坐姿休息
      │ 持续一段时间后
      ▼
  lie_down (0.75s, 锚点 0.86→0.78)
      ▼
  sleep_idle (循环 1.33s, 锚点 0.78)  ← 躺睡 + 睡眠气泡特效
      │ 触发 wake 行为
      ▼
  wake_up (0.8s, 锚点 0.78→0.90)
      ▼
[站姿 idle_breath]
```

### 4.3 锚点过渡规则（关键实现约束）

锚点在子动作之间**必须连续变化**，不能瞬时跳变：

| 过渡段 | 锚点 y 变化 | 插值方式 |
|---|---|---|
| sit_down | 0.90 → 0.86 | 6 帧线性插值 |
| lie_down | 0.86 → 0.78 | 6 帧线性插值 |
| wake_up | 0.78 → 0.90 | 8 帧线性插值 |

**计算公式**：
```
screen_y(frame_i) = ground_y - sprite_height * anchor_y(frame_i)
anchor_y(frame_i) = lerp(anchor_y_start, anchor_y_end, i / (total_frames - 1))
```

**理由**：R122 §五 2 要求「不同动作转换时如何避免角色突然跳位置」。锚点随姿态连续插值，角色的「着地点」在屏幕上保持平滑移动。

### 4.4 sleep 组一致性检查点

| 检查项 | 通过标准 |
|---|---|
| sit_down 6 帧脚部/臀部位移连续 | 无跳变 |
| 坐姿 6 帧臀部 y 坐标 | 全帧一致（±1 px @512） |
| 躺姿 6 帧肩部/侧身 y 坐标 | 全帧一致（±1 px @512） |
| wake_up 可逆性 | wake_up 是 sit_down+lie_down 的严格逆序（帧数可不等） |
| 循环接缝 | sit_rest 4 帧循环、sleep_idle 4 帧循环均无跳变 |
| 锚点连续性 | 整个状态机转换过程中，屏幕 y 无阶跃 |

## 六、GATE 3 制作优先级与工时估算

| 优先级 | 动作 | 帧数 | 难度 | 说明 |
|---|---|---|---|---|
| **P0** | `idle_breath` | 6 | 低 | 最简单，先验证立绘 → 序列帧的管线 |
| **P0** | `blink` | 3（图层） | 低 | 验证图层切换方案 |
| **P1** | `walk_left` + `walk_right` | 8 × 2 | 中 | 验证循环 + 镜像导出 |
| **P2** | `sit_down` + `sit_rest` | 6 + 4 | 中 | 首次遇到锚点变化 |
| **P2** | `lie_down` + `sleep_idle` + `wake_up` | 6 + 4 + 8 | 中高 | 锚点连续插值 |

**建议顺序**：idle → blink → walk → sit → sleep。
每完成一组先验证一致性，再进入下一组，避免后期返工。
