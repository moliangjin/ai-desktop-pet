
**同源证据**：A6b 中的角色像素与 A1_MASTER_FRONT_CLEAN.png 是同一份资产，仅经过等比缩放与 alpha 合成，**未经过任何生成式重绘**。

### 4.2 桌面底图的性质声明（重要）

`A6_desktop_base_synthetic.png` 是**程序化生成的合成 macOS 风格桌面**（`make_desktop_plate.py` 输出），理由：

- 真实用户桌面截图（`screencapture`）包含用户的私有信息（文件名、通知、书签），**不适合作为交付素材**
- R122 §三 A6 的目的是验证「角色在桌面观感下的可读性与比例」，不要求桌面本身是用户真实屏幕

**该底图不含任何用户私有信息，不冒充真实用户截图。** 已在文件名与文档中双重标注。

### 5.1 白底抠图的关键技术点

角色的白色实验服（#F5F8FA）与白背景在亮度上无法用全局阈值区分。**直接按「近白即透明」会把衣服抠穿。**

本轮采用 **flood fill 边缘扩散**：从画布四边出发做 BFS，只删除「与画布边缘连通」的白色区域。被深色描边包围的白色制服自然保留。

验证结果：透明样板的白色制服完整无破损（见 `A6c_pet_window_200x240_readability.png` 的 4× 放大图）。

### 7.4 头身比实测 3.34 而非设定 2.5

自动检测估算的头身比约为 **3.34**（高度 ÷ 头部 30% 区域高度）。需要说明：

- 该估算采用「上 30% 区域」作为头部近似，Q 版角色的头发外扩会使头部视觉高度被低估/高估
- 目视 A1 立绘：头部（含发型）约占整体高度的 30%，即约 **3.3 头身**
- R119 设定与 PRD §三要求「约 2.5 头身」

**这是一个需要用户裁决的偏差**：本轮 A 系列（由 R119 A 原图 i2i 细化而来）实际呈现约 3.3 头身，与 2.5 头身设定有差距。Mavis 未擅自改变角色比例以强行匹配 2.5，因为那会改变用户已通过 GATE 1 认可的 A 方案视觉方向。**请在 GATE 2 审核时明确是否需要调整到 2.5 头身。**
