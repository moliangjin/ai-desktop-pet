# R127 头身比真实测量报告（文字版）
> 本报告由 R127 §四 P0-2 整改要求生成。R122 旧的"height*0.30 倒推"算法已废弃。
> 关键点 100% 由算法在图像上自动检测，无任何预设。

## 一、关键点检测方法
- 头顶 (top_y)：画布顶向下扫描，**第一行出现前景像素**的 y 坐标
- 脚底 (bottom_y)：画布底向上扫描，**最后一行出现前景像素**的 y 坐标
- 下巴/颈连接 (chin_y)：在脸部水平中心 40%-60% 范围内，**肤色像素 y 分布的 70% 分位数**
  - 皮肤判定：R>200, G>170, B<215, R>B
  - 不用预设比例，不用「头发结束」启发式（领口白会被误判）
  - 背面无脸 → fallback 到画布上 1/3 位置（标为不参与一致性）

## 三、跨视角一致性

- 3 个有效视角（A1/A2/A4）头身比：[3.574, 3.925, 3.504, 3.998]
- 极差：0.494
- 一致性判定：极差 < 0.5 = 高度一致 ✅
