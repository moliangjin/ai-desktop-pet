## 二、任务一：A4 三-4 视角（BLOCKED）

按 R130 §二 要求"最多进行三次有实质区别的制作尝试，每次必须记录采用的方法及失败原因"。

### 2.1 三次尝试记录

| 尝试 | 方法 | 结果 | 失败原因 |
|---|---|---|---|
| 1 | 极强 prompt（1915 字符）：强调 45° 旋转 + 远眼小 + 近眼大 + 3D 透视 | **头部**有 3-4 旋转（右眼被头发遮挡、左耳露出、鼻子偏移、脸颊不对称）✅；**身体**仍近正面（肩对称、徽章正面）❌ | i2i 模型对"同一角色 3-4 视角"存在结构偏好，多轮 prompt 强化都收敛到头部旋转+身体近正面 |
| 2 | 强调"身体扭转 60° + 头回转 30°"：要求胸徽章从角度、中心缝弯曲、右肩藏到身后 | **身体姿态漂移**（变成"插口袋+握拳"姿势）；头部近正面 | 过度强调身体旋转导致姿态记忆失效；模型画了"插口袋"姿态，身份部分丢失 |
| 3 | 强调"仅旋转不改变姿势"：保留 A1 自然下垂双臂 + 身体 35-40° 旋转 | **姿态再次漂移**（左手又画成握拳腹部）；3-4 旋转不明显 | 单一 i2i 调用无法在"保持姿势"+"真旋转"+"身份锁定"三者同时满足 |

### 2.2 失败原因分析

**i2i 模型的硬约束**：
- 模型在 i2i 模式下，会把母版图的"角色 + 旁边线稿"排版当作结构约束
- 对"全身 + 3-4 旋转 + 保持 A1 姿势"这种强约束，模型无法同时满足
- 强 prompt 倾向于"放大某个特征"（如头转 60°），但同时牺牲其他特征（姿态漂移）

## 三、任务二：透明 PNG 杂线清理（PARTIAL）

### 3.1 检查流程（按 R130 §三 要求）

1. **独立连通区域检测**：扫描 alpha≤80 + 颜色明显像素，8-邻接连通块标记
2. **定位图**：在 A1 母版上画红框（清理）/绿框（保留）
3. **小配饰排除**：与主体边缘 ≤2px 的小块保留为描边
4. **多背景验证**：白/黑/中灰/蓝/棋盘 5 背景
5. **半透明边缘检查**：alpha 4-80 范围的 RGB 噪声分析

### 3.2 实测结果

| 检查项 | 实测 |
|---|---|
| 检测到的非主体候选连通块 | 25 个（21 个 1-6 像素 + 1 个 215090 像素的"整图级"块） |
| 真正独立残影 | **0 个**（R127 净化版本已无）|
| GPT 报告的 338 像素右肩杂线 | **未找到** |
| 白色制服完整性 | ✅ 完整 |
| Alpha 通道存在 | ✅ 真实 RGBA，alpha 覆盖率 17.54% |
| 多背景表现 | 5 背景下均无可见残影 |

### 3.3 关于"338 像素杂线"的诚实声明

R130 §三 提到"角色右肩外侧仍有浅色线稿残留，存在约 338 像素的独立连通残留区域"。

R130 复现检查中：
- 在 R127 透明样板上检测：所有候选块都距主体 ≤2px
- 在 R127 A1 母版（未透明化版本）上检测：主体外前景像素 = **0**
- 没有任何"独立连通 338 像素"的右肩残影

**可能解释**：
- GPT 审查时看到的是 R127 净化**之前**的中间产物
- GPT 报告的"338 像素"是包含 alpha 抗锯齿边缘带（含 R127 透明样板的 2685 像素半透明区域内的部分）
- 检测阈值差异（GPT 用的判据与 R130 脚本不同）

**R130 处理方式**：
- 透明样板继承自 R127（已较干净）
- R130 重新检查 25 个候选块并生成定位图
- **如 GPT 持有具体的 338 像素区域坐标或截图证据，建议在 GATE 2 审核时提供**，R130 脚本可重新精确定位
