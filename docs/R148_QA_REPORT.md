## 一、素材实测：这次为什么必须动素材

### 1.1 先把"倒退"变成可测量的量

不能靠文件名、不能靠坐标正负、不能靠动画名。本轮定义了**鞋尖几何**判据（`18_R148_direction_verify.py`）：

1. 用颜色把**靴子**像素与**浅蓝长袜 / 皮肤**分开，取角色最底部 16% 高度带（纯靴子区）
2. 按 x 分成左/右两只靴
3. **落地靴** = 靴底 y 最大（贴地）的那只；两只靴底同高 → 该帧是"并立站姿"，无步向
4. **鞋尖朝向** = 靴体重心 x 相对**靴筒口 x**（靴子最高一行的像素中心）的偏移方向
   （靴体是从靴筒口朝鞋头延伸的，重心落在鞋头一侧）→ `−1` 鞋尖朝左，`+1` 鞋尖朝右

实测结果（`evidence_r148_direction.json`）：

| 动作 | 步态帧 | 落地靴 | **鞋尖朝向** | 判定 |
|---|---|---|---|---|
| `walk_left`（R138 原始） | 3 | 全部在左 | `[-1, -1, -1]` | **PASS** |
| `walk_right`（R138 原始） | 3 | 全部在左 | `[-1, -1, -1]` | **FAIL** ← 客观复现用户投诉 |
| `walk_right`（R148 派生） | 3 | 全部在右 | `[+1, +1, +1]` | **PASS** |

> 旧 `walk_right` 的落地靴在**画面左侧**且鞋尖**朝左** → 窗口向右移动时，画面里人却在向左迈 = 倒退。
> **用户的观察被独立复现**，本轮不再有任何"方向靠推断"的成分。

### 1.2 排除了帧序 / 映射问题

- 两组素材的抬脚腿序列几乎相同（`walk_left` 01/02/03 抬右脚；`walk_right` 01/02/03 也抬右脚）→ **不是"帧放反了"**，调帧序救不了。
- 两组素材**不是同一套帧**（交叉像素差异 68k~152k），也不是互为镜像 → 不是"改个文件名"能解决的。
- 唯一能改变"哪只脚在前 / 鞋尖朝哪边"的方式 = **整体水平镜像**（任务书授权路径）。

### 1.3 为什么源素材选 `walk_left` 而不是 `walk_right`

逐帧放大比对（`/tmp` 实测图）发现 **R138 两组行走素材的服装本身就不一致**：

| | `walk_left` | `walk_right`（旧） |
|---|---|---|
| 腿袜 | **左腿长袜 + 右腿裸腿** | **双腿都长袜** |
| 手臂 | 自然下垂 | 右手横在胸前 |
| 胸口烧瓶徽章 | 角色**左胸**（观者右侧） | 角色**左胸**（观者右侧） |

若镜像旧 `walk_right` 来用，**转身瞬间会出现"裸腿变成长袜"的换装跳变**（服装不一致）。
若镜像 `walk_left` 来用：两个方向服装完全一致，转向时只是"同一身衣服的左右腿互换"，与"角色转身"的直觉一致。

→ **选定：以 `walk_left` 4 帧为源整体镜像派生 `walk_right`。**

### 1.4 镜像的非对称代价：实测 + 修复

R147 曾以"发型左右不对称，镜像会破坏角色身份"为由否决镜像。R148 重新用测量复核：

| 部位 | 镜像后差异 > 12 的像素占比 | 结论 |
|---|---|---|
| 脸部（眼/鼻/嘴 100–300） | 60.78% | 差异来自**眉毛/发丝走向**，五官本身左右对称 → 镜像后仍是**同一个角色**（并排对比图确认） |
| 头发上半 | 35.13% | 刘海左右互换，仍是同款发型 |
| 整头 | 56.09% | — |
| **胸口烧瓶徽章（42×46）** | 42.9% | **这是唯一的身份标记** → 必须修 |

修复方案（`17_R148_mirror_derive.py`）：

1. 用 idle 站姿帧的徽章做模板，NCC 定位每帧徽章位置（实测 ncc 0.81~0.99）
2. 分离"墨迹"（描边 + 柔影）与干净外衣
3. **擦除**镜像后残留在另一侧的"镜像徽章"：在**镜像图自己**上做**调和扩散修补**（保留镜像外衣自身着色，不贴源图，避免亮度错位出鬼影）
4. **归位**：把徽章**按原样（不镜像）**搬回角色自己的左胸；用**羽化 alpha**（半径 5px）融合 + **非墨迹区均值色差对齐**，消除融合边缘的亮度阶跃
5. 徽章位置用**逐帧**模板定位，不是硬编码坐标

修复后实测：

| 校验 | 帧 0 | 帧 1 | 帧 2 | 帧 3 |
|---|---|---|---|---|
| 徽章区外 vs 纯镜像 差异像素 | **0** / 4,175,904 | **0** | **0** | **0** |
| 徽章 NCC（正/翻转） | 0.86 / 0.25 | 0.96 / 0.26 | 0.99 / 0.24 | 0.96 / 0.31 |
| 徽章相对身体中心 | +49.5px | +52.5px | +47.5px | +46.5px（观者右侧 = 角色左胸） |

→ 徽章**没被镜像**（正相关远高于翻转相关），且**位置与 `walk_left` 一致**。

## 五、残余限制（如实记录，不粉饰）

1. **原 R138 的 `walk_right` 4 帧不再被运行时使用**
   它们保留在 `character_R138/walk_right/` 内、**字节未变**（SHA256 校验通过），但 manifest 不再引用——因为它们的落脚脚/鞋尖与 `walk_left` 同向，直接播放就是倒退观感。
   → 运行时实际加载 23 帧 = **19 张 R138 原帧 + 4 张派生帧**，仍是 23 个互不相同的文件（资产门禁口径不变，R147 e2e TTA1 已验）。
   → 若将来要恢复原 `walk_right` 4 帧，需要重画或修出"右脚在前、鞋尖朝右"的版本。

2. **`walk_right` 现在是 `walk_left` 的镜像 —— 接缝与"刚体感"随之继承**
   R147 §5.2 已记录 `walk_left` 循环接缝比 `walk_right` 明显（1.55 vs 1.03）。R148 把 `walk_right` 换成 `walk_left` 的镜像后，**两个方向的接缝比都变成 1.55**，慢速播放时"回到站姿"的那一下衔接现在左右一致（此前左右不一致）。这是取舍，不是回退：换来的是服装一致 + 方向正确。

3. **左移仍有约 20px/s 的脚步滑动**（资产固有，未变）
